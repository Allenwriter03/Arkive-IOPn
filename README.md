# ARKIVE 
### Phygital Document Vault — Built on OPN Chain

> Your world, preserved on-chain.

## What is ARKIVE?
ARKIVE is a decentralized document storage platform built on OPN Chain. 
Users can upload their most important documents — IDs, certificates, 
contracts, property deeds — store them permanently on IPFS, and 
retrieve them anywhere, anytime, with cryptographic proof of authenticity.

## The Problem
People lose critical documents. Physical copies get damaged or destroyed. 
Centralized digital storage gets hacked or shut down. There is no 
trustless, permanent, verifiable way to store documents today.

## The Solution
ARKIVE connects the physical world to OPN Chain:
- Upload any document from your device
- File stored on IPFS via Pinata (decentralized storage)
- Document hash recorded permanently on OPN Chain smart contract
- Only your wallet can access your documents
- Anyone can verify authenticity without seeing the contents

## Tech Stack
- **Frontend:** HTML, CSS, JavaScript
- **Blockchain:** OPN Chain (EVM-compatible)  
- **Smart Contract:** Solidity
- **File Storage:** IPFS via Pinata
- **Wallet:** MetaMask + ethers.js
- **Hosting:** Netlify

## How It Works
1. Connect MetaMask wallet
2. Upload your document
3. File encrypted and sent to IPFS
4. Document CID recorded on OPN Chain
5. Retrieve anytime with your wallet
